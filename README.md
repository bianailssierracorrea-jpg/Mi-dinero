# Mi Dinero — Proyecto Offline

Aplicación Android de finanzas personales y cambio de divisas, diseñada para funcionar localmente sin permiso de Internet.

## Compilación desde GitHub Actions

1. Sube todo el contenido de este proyecto a un repositorio de GitHub.
2. En GitHub abre **Actions**.
3. Selecciona **Compilar Mi Dinero APK**.
4. Pulsa **Run workflow**.
5. Cuando termine correctamente, abre la ejecución y descarga el artefacto **MiDinero-APK**.
6. Dentro estará `app-debug.apk`.

La conexión a Internet se utiliza para descargar dependencias y compilar en GitHub. La aplicación instalada no necesita Internet para su funcionamiento.
